⚡ About the App

Nub to Word BDT is an all-in-one productivity app concept designed for everyday users in Bangladesh. It combines a Bangladeshi Taka number-to-words converter, document scanner, PDF creator, and smart calculator in one clean interface.

Built around a minimalist, Nothing-inspired design with bold red accents, smooth animations, and an AMOLED-friendly dark mode.
